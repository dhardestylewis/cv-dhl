# LinkedIn Profile Archive

This archive preserves 10 verified local PDF snapshots of Daniel Hardesty Lewis's LinkedIn profile, arranged chronologically. Each retained PDF identifies Daniel Hardesty Lewis on its first page. The timestamp embedded by the PDF producer is the authority for dating and ordering. Windows file modified times are not used for the sequence.

`v10` is the latest saved export: October 15, 2026, 17:42:44 Eastern Daylight Time. The documents are historical snapshots, not evidence that the live profile has a given current state.

## Filename convention

`linkedin-profile-vNN-YYYYMMDD-HHMMSS.pdf`

`NN` is the chronological snapshot number. The date and time reproduce the PDF's embedded `CreationDate` in the timezone stated by that document.

## Repository normalization

The prior repository held two byte-identical names for the June 13, 2026 snapshot. The precise canonical filename is now `linkedin-profile-v08-20260613-141733.pdf`; the duplicate name was removed from the active tree. Git history retains the prior copy.

Files identified only by the generic `Profile*.pdf` filename, but whose first pages named other people, were excluded from this archive. Their original Downloads copies were left untouched. All retained PDFs were verified against their source with SHA-256 before being added. No authenticated LinkedIn session or profile page was opened to make this archive.
