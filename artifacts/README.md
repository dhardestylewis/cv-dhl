# LinkedIn Profile Archive

This archive preserves 20 distinct local PDF snapshots of Daniel Hardesty Lewis's LinkedIn profile, arranged chronologically. The timestamp embedded by the PDF producer is the authority for dating and ordering. Windows file modified times are not used for the sequence.

`v20` is the latest saved export: October 15, 2026, 17:42:44 Eastern Daylight Time. The documents are historical snapshots, not evidence that the live profile has a given current state.

## Filename convention

`linkedin-profile-vNN-YYYYMMDD-HHMMSS.pdf`

`NN` is the chronological snapshot number. The date and time reproduce the PDF's embedded `CreationDate` in the timezone stated by that document.
